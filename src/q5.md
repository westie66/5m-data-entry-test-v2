# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
_A kernel is a middleman that connects software to hardware resources._

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
_Not accurate. WSL provides a Linux environment inside/alongside Windows, but Windows remains the main host operating system. WSL can interact with Windows files, processes, and networking, so the two environments are not totally independent._

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
_A terminal (emulator) is the window or application where you type commands, while a shell is the program that interprets your commands and executes them. 
Example: Windows Terminal (terminal) and Powershell (shell)_
